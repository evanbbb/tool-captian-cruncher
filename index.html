Fixed Order

pngquant → oxipng → zopflipng

The order is fixed so the generated command stays sensible: quantize first, clean up second, optional slow final pass last.

pngquant

Main Lossy Step

Biggest size drop. Converts to a more efficient 8-bit PNG when it can do so within the selected quality range.

oxipng

Lossless Cleanup

Metadata stripping and structural optimization. The alpha option is visually lossless but still technically lossy.

zopflipng

Slow Final Pass

Slowest step in the chain. Useful when every last KB matters.
