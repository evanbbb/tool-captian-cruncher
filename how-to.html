macOS Guide

How To

Install the local dependencies, grab the right pathname, switch into the folder you want, and run the one-line command generated by Captain Cruncher.

Homebrew → Pathname → Terminal → Command

These instructions are for macOS only. Nothing uploads anywhere. The builders only generate local shell commands.

Mac only. You need Terminal and Homebrew for the install commands below.

Quick Start

Typical macOS Flow

brew install pngquant oxipng zopfli jpegoptim jpeg-turbo ffmpeg gifski
cd /Users/you/path/to/folder
# paste the builder's one-line command here

Step 1

Install Homebrew and Dependencies

Set up Homebrew first, then install the compression tools used by the builders.

a. Install Homebrew

If Homebrew is not installed yet, run this once in Terminal. 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

b. Install Dependencies

After Homebrew is ready, install the compression tools Captain Cruncher uses on macOS. 

brew install pngquant oxipng zopfli
brew install jpegoptim jpeg-turbo
brew install ffmpeg gifski

You can also install everything in one pass: brew install pngquant oxipng zopfli jpegoptim jpeg-turbo ffmpeg gifski

Step 2

Get the Pathname

  1. Find the source file in Finder.
  2. Hold Option, right-click the file, then choose Copy "filename" as Pathname.
  3. Paste that full path into the builder input field.
  4. If the copied path includes quotes, that is fine. Captain Cruncher strips matching outer quotes automatically.

Fast fallback: drag a file or folder directly into Terminal to paste its full path.

Step 3

Switch to the Folder

Open Terminal and change into the folder that contains the source asset before running the generated command. 

cd /Users/you/path/to/folder

Step 4

Run the Terminal Command

  1. Open the PNG, JPEG, or GIF builder.
  2. Paste the file pathname into the input field.
  3. Tune the settings you want.
  4. Copy the One-Line Command.
  5. Paste it into Terminal and press Return.
  6. The new output file is written next to the original with the suffix shown in the builder.

Troubleshooting

When Commands Fail

  1. If Terminal says command not found, install the missing Homebrew package.
  2. If the path has spaces, keep it quoted when using plain Terminal commands.
  3. If you want to inspect the output folder after a run, use open ..
